Quick Start Guide Which HDD Do I Have?
What is launcHER?
launcHER is a standalone PlayStation 2 forwarder engineered specifically to launch Ember from supported storage devices while preserving the hardware environment and driver state Ember needs after handoff.

It is not an OSD replacement, HDD Browser, game manager, KELF installer, or menu system. It does one focused job:
Find Ember wherever you keep it, prepare that storage device correctly, pass Ember the game it should launch, and get out of the way without destroying what Ember needs.

HDD Users: Read This First

launcHER does NOT require a dedicated HDD partition. The __.EMBER APA partition shown in some examples is purely an organizational suggestion — not a technical requirement. You do not need to create __.EMBER to use launcHER.

Furthermore, "HDD" means completely different storage technologies on the PS2. Match the path to where Ember actually lives:

Where Ember is stored Storage Type launcHER Path in CNF
USB flash drive / USB HDD / USB SSD USB Mass Storage (FAT32/exFAT) path=mass?:/EMBER/ember.elf
Internal HDD using exFAT Internal ATA BDM path=ata:/EMBER/ember.elf
APA-Jail / Mixed APA+exFAT (Ember on exFAT side) Internal ATA BDM path=ata:/EMBER/ember.elf
Internal APA/PFS HDD (Ember inside a PFS partition) APA / PFS Partition Mount path=hdd0:<PARTITION>:pfs:/EMBER/ember.elf
APA-Jail (Ember inside an APA partition, e.g. __common) APA / PFS Partition Mount path=hdd0:__common:pfs:/EMBER/ember.elf

Why Ember Needs a Specialized Forwarder

Ember is not an ordinary standalone ELF that can simply be loaded into memory without preparation. It relies on its caller to provide:

  • Bare Game Folder Argument — Ember expects the clean subfolder name under EMBER/games/ (e.g. Soul Blade), not a full path, nor a .cue filename.
  • DEV9 Hardware Power Preservation — For ATA, APA/PFS, and network devices, turning off DEV9 on exit destroys the storage interface. launcHER keeps DEV9 powered through -dev9=NICHDD or -dev9=NIC.
  • Active PFS Mount Preservation — In APA/PFS mode, Ember expects to continue accessing files through pfs0:/. launcHER mounts the partition and hands control over with argv[0] = pfs0:/EMBER/ember.elf while skipping the raw loader-facing hdd0: token.
  • Clean IOP Storage Drivers — launcHER initializes clean, conflict-free drivers for ATA, USB, MMCE, MX4SIO, i.Link, UDPBD, and UDPFS.

Key Architectural Features

  • Zero Configuration In-Place Corruption — Fully non-destructive APA path parser supporting classic :pfs:, numbered :pfs0:–:pfs9: (OPL DB), wLaunchELF +OPLpfs0:, and unadorned partition paths.
  • Filename-Independent Quickboot — You can rename launcHER.elf to Soul Blade.ELF; it automatically resolves its parent directory and loads launcHER.CNF.
  • Case-Insensitive Config Discovery — Automatically searches for launcHER.CNF, launcHER.cnf, launcHER.CFG, and launcHER.cfg.
  • Pure Standalone Footprint — Stripped of legacy OSDMenu, MBR installers, and CD/DVD fluff for lightning-fast initialization.
