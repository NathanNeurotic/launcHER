## 6. How to check a tree

Host tests, from the repository root, one file after another (two runs at
once collide on `build/pops-host`). Set all three temporary-folder
variables; Git Bash sets `TMPDIR` and Python prefers it:

```sh
export TMP=<empty dir> TEMP=<same> TMPDIR=<same>
for t in tools/test_*.py; do python "$t" || echo "FAILED $t"; done
```

Run them once with no reference inputs (this is what CI does; tests that
need the originals skip) and once with `POPS_TEST_ELF` (Sony `POPS.ELF`),
`POPSTARTER_TEST_ELF` (POPStarter r13 `MAIN` profile ELF) and
`POPS_TROJAN_CORPUS` (a folder of community fix files) set. Optional:
`POPS_HANDOFF_ELF` (a built `launcher_unc.elf`) for `test_pops_handoff.py`,
`POPS_RESIDENT_BIN` (a built `pops_resident.bin`) for the TROJAN chain
tests. The originals and the corpus are never committed.

Target build. In a plain clone:

```sh
git submodule update --init launcher/iop/mmceman
docker run --rm -v <repo>:/workspace -w /workspace ghcr.io/ps2homebrew/ps2homebrew:main \
  sh -c "apk add cmake && git config --global --add safe.directory '*' && cmake -B build-pr23 && cmake --build build-pr23 --target launcHER"
```

In a git worktree, also mount the main checkout at the same path it has on
the host, or git cannot resolve the worktree inside the container (the
build still works; the version reads `unknown`). Add
`-DLAUNCHER_BOOT_TRACE=ON -DDEBUG=ON` for the trace build the emulator runs
read. The build runs `tools/check_pops_handoff_layout.py` after linking and
prints `handoff layout: OK`.

Emulator: the scripts are in
[handoff/2026-11-11/emulator-harness/](handoff/2026-11-11/emulator-harness/REPORT.md).
They expect a private copy of PCSX2, a BIOS and disk images that are not in
the repository. Tier 2 (EE interpreter, ATA image, from "Transferring
control to trampoline" or, for a release build, "SDR driver version" to
POPS's "Interlaced (FIELD)" video setup, failing on "Trap exception at") is
the check that shows the handoff defect; tier 1 ends before the handoff
code runs.
