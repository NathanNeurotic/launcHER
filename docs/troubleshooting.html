Troubleshooting & Errors

When launcHER encounters a filesystem or hardware handoff error, it displays a concise diagnostic code on screen. Use this reference to diagnose and resolve errors quickly.

Error Code Diagnostic Table

Error Message POSIX / PS2 Meaning Root Cause & Solution
Quickboot failed: -19 -ENODEV (No such device) 1. OPL DB PFS token issue: Older versions of launcHER failed when OPL DB passed :pfs0:/ paths. Upgrade to the latest release.
2. Partition does not exist: The partition specified in path=hdd0:<PARTITION>... does not exist on the drive. Check your partition list in wLaunchELF.
3. Missing DEV9 flag: Internal drives need arg=-dev9=NICHDD.
Quickboot failed: -2 -ENOENT (No such file) 1. Missing CNF file: launcHER.CNF is missing from the folder where the ELF was launched.
2. Missing ember.elf: ember.elf was not found at the path defined by path=. Verify spelling and case sensitivity.
Quickboot failed: -6 -ENXIO (No such device or address) The physical hardware (internal HDD or USB drive) did not respond to driver initialization. Verify the Network Adapter is firmly screwed into the PS2 expansion bay, or try a different USB port.
Quickboot failed: -22 -EINVAL (Invalid argument) Syntax error in launcHER.CNF or a malformed path string. Verify that there are no extra quotation marks or leading spaces in your path= or arg= lines.

Black Screen After Launch Checklist

If launcHER successfully starts Ember, but the screen stays black or returns to OSDSYS:

1. Check the Game Argument
Did you pass arg=Soul Blade or did you pass arg=Soul Blade/Soul Blade.cue?
Ember requires the bare folder name. Passing a file path or .cue file will cause Ember to fail to load disc tracks.
2. Verify bios.bin is Present
Ember requires a genuine PlayStation 1 BIOS image named bios.bin inside EMBER/: 
EMBER/
├── ember.elf
├── bios.bin         <-- Required!
└── games/
3. Check DEV9 Persistence Flag
If you are launching from internal exFAT (ata:/) or an APA partition (pfs0:/), Ember needs the internal hard drive powered after handoff.
Ensure your launcHER.CNF includes: 
arg=-dev9=NICHDD

Submitting a Bug Report

If you encounter a reproducible crash or hardware incompatibility, please open an issue on the launcHER GitHub Issues tracker including:

  • PS2 Model: (e.g. SCPH-39001, SCPH-50004, SCPH-70012)
  • Storage Device & Adapter: (e.g. Official Sony Network Adapter with SATA kit, Gamestar clone, USB 3.0 flash drive)
  • Filesystem Layout: (e.g. Pure exFAT, APA/PFS, APA-Jail)
  • Ember Location: Exact path where ember.elf is stored
  • Complete launcHER.CNF Content: Copy/paste the full text
  • Versions: launcHER commit/release and Ember version
  • On-Screen Error: Exact text displayed on the screen before the failure
