Building from Source

launcHER uses modern CMake and builds with the official PS2SDK / ps2dev toolchain.

Prerequisites

  • ps2dev / PS2SDK: Environment variables $PS2DEV and $PS2SDK must be exported.
  • CMake: Version 3.13 or newer.
  • Git: With recursive submodule support.

Build Instructions

# 1. Clone repository with submodules
git clone --recursive https://github.com/NathanNeurotic/launcHER.git
cd launcHER

# 2. Configure build tree
cmake -B build

# 3. Compile standalone release
cmake --build build --target launcHER

The compiled binary and quickboot template are generated under: 

build/release/
├── launcHER.elf
└── launcHER.CNF

CMake Build Options

Option Default Description
-DENABLE_PRINTF=ON OFF Enable verbose console printf debugging output.
-DUSE_EESIO=ON ON Direct debug log output through EE SIO serial hardware.
-DDEBUG=ON OFF Disable ELF stripping to preserve full debugging symbols for GDB.

Building with Docker

If you do not have a local ps2dev environment installed, you can use the official PS2DEV container: 

docker run --rm -v "$(pwd):/__w/launcHER/launcHER" -w "/__w/launcHER/launcHER" \
  ghcr.io/ps2homebrew/ps2homebrew:main \
  sh -c "cmake -B build && cmake --build build --target launcHER"
