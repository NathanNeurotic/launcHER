What's in the Package

Every release provides:

File Description Required?
launcHER.elf The compiled standalone PlayStation 2 forwarder binary. May be renamed to match game titles (e.g. Soul Blade.ELF). Yes
launcHER.CNF The quickboot configuration template containing documented profiles for USB, ATA exFAT, APA/PFS, MMCE, and UDPBD. Yes
launcHER.zip Convenience archive bundling both launcHER.elf and launcHER.CNF ready to extract onto console storage. Optional
No KELF Required
Unlike legacy OSDMenu installations, standard launcHER operation does not require KELF encryption, MBR injection, or Sony magicgate header signing.
