OPL APPS Integration

launcHER is designed to be the ultimate companion for Open PS2 Loader's Applications (APPS) page. You can list individual Ember games directly on your OPL carousel or list with custom names and 3D cover art.

The Renamed ELF Architecture

Traditional loaders often require the configuration file to match the ELF name (e.g. Game.ELF needing Game.CNF).

Filename Independence
launcHER intentionally eliminates this requirement. You can rename a copy of launcHER.elf to any title you want, while its configuration file remains launcHER.CNF: 
Soul Blade/
├── Soul Blade.ELF    # Renamed copy of launcHER.elf
└── launcHER.CNF      # Quickboot configuration

When OPL launches Soul Blade.ELF, the ELF automatically detects its launch path, strips its own filename, and opens launcHER.CNF in the same folder.

Folder Layouts by Storage Backend

1. Internal APA HDD (+OPL partition)

+OPL/
└── APPS/
    ├── Soul Blade/
    │   ├── Soul Blade.ELF      # Renamed launcHER binary
    │   ├── launcHER.CNF        # Configuration template
    │   └── title.cfg           # Optional OPL title descriptor
    │
    └── Final Fantasy VII/
        ├── Final Fantasy VII.ELF
        ├── launcHER.CNF
        └── title.cfg

2. USB Storage

mass0:/
└── APPS/
    └── Soul Blade/
        ├── Soul Blade.ELF
        └── launcHER.CNF

3. Internal exFAT HDD

ata:/
└── APPS/
    └── Soul Blade/
        ├── Soul Blade.ELF
        └── launcHER.CNF

OPL title.cfg Specification

OPL reads title.cfg inside each application directory to determine its display name, boot target, and version details: 

title=Soul Blade
boot=Soul Blade.ELF
version=Ember 1.0
developer=Namco
genre=Fighting
players=players/2

Save this as title.cfg directly beside Soul Blade.ELF and launcHER.CNF.

Adding Cover Art to OPL

In Open PS2 Loader and RiptOPL, application cover art is placed in the standard ART/ directory using the ELF filename as the prefix: 

ART/
├── Soul Blade.ELF_COV.jpg      # Front cover (or 3D Coverflow case)
├── Soul Blade.ELF_COV2.jpg     # Back cover
├── Soul Blade.ELF_ICO.png      # Disc icon
└── Soul Blade.ELF_BG.jpg       # Background wallpaper

OPL DB and Official OPL Compatibility

In OPL Daily Builds (OPL DB) and official ps2homebrew OPL, internal HDD application paths are delivered with numbered PFS tokens: 

argv[0] = "hdd0:+OPL:pfs0:/APPS/Soul Blade/Soul Blade.ELF"

POPS Games in OPL APPS

You can list Sony POPS games in OPL APPS using two methods:

Method 1: launcHER.CNF Quickboot

Place a renamed copy of launcHER.elf alongside a launcHER.CNF file pointing to your .VCD: 

APPS/Crash Bandicoot/
├── Crash Bandicoot.ELF      # Renamed copy of launcHER.elf
├── launcHER.CNF             # Contains: path=mass0:/POPS/Crash Bandicoot.VCD
└── title.cfg

Method 2: POPStarter Compatibility Mode (XX. Prefix)

launcHER natively recognizes POPStarter's naming standard. If you rename the ELF with an XX. or SB. prefix (such as XX.Crash Bandicoot.ELF) in the same directory as Crash Bandicoot.VCD: 

POPS/
├── POPS_IOX.PAK
├── Crash Bandicoot.VCD
└── XX.Crash Bandicoot.ELF   # Copy of launcHER.elf

When launched without a CNF file, launcHER strips the XX. prefix, identifies Crash Bandicoot.VCD, and launches POPS without extra configuration. See the POPS & PS1 Setup Guide for complete details.
