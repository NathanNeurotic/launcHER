Credits & Lineage

launcHER deliberately maintains its upstream lineage visible. It stands on the shoulders of dedicated PlayStation 2 homebrew engineers.

nuno6573 →

Solution concept, architectural selection, and guidance on using a tailored launcher forwarder for Ember's external environment. Thanks to nuno for the information and breakthrough idea.

pcm720 →

Creator of OSDMenu and the standalone OSDMenu Launcher from which launcHER is derived. The core device handlers, loader architecture, and foundational execution model originate from this work.

Gageformer →

Creator of Ember, the high-performance PlayStation 1 emulator core that launcHER exists to launch.

Eliminator / eliminator1403

PS2 hardware validation, real-console regression testing, device-side debugging, and the filename-independent launcHER.CNF quickboot refinement used for renamed OPL APPS entries.

NathanNeurotic (Ripto) →

launcHER fork, Ember handoff integration, APA/PFS driver persistence, robust OPL DB token parser, standalone build profile, documentation site, and release packaging.

PS2SDK & ps2dev Community

The global PlayStation 2 homebrew open-source community whose decades of reverse engineering, drivers, and toolchains make projects like launcHER possible.
