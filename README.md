# launcHER

Standalone Ember-focused PS2 ELF launcher derived from OSDMenu Launcher.

## Release assets

Each release provides:

- `launcHER.elf` — standalone launcher
- `launcHER.CNF` — editable Ember quickboot/device example template
- `launcHER.zip` — ready-to-copy package containing the ELF and CNF
- GitHub's automatic source archives

The standalone build keeps Ember-relevant storage transports and removes the OSDMenu/HOSDMenu/MBR/KELF packaging path from this fork.
